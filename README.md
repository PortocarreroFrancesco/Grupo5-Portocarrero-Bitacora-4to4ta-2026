# Grupo5-Portocarrero-Bitacora-4to4ta-2026
Bitácoras de mi trabajo en el proyecto final de la materia Proyecto Informático 1.

Hoy hicimos el trabajo de investigación y esquema de un componente del proyecto final, como nuestro proyecto final va a tratar de una carrera de caballos con caballos de cartón, pensamos en implementar un sensor de distancia ultrasónico para ver cual caballo llegaba primero a la meta.
Aprendí como hacer las conexiones desde el sensor al Arduino, y como es su respectivo código para que funcione correctamente gracias a un trabajo que explicaba como funciona el sensor: https://www.tinkercad.com/things/eHtdvT6aNWc-sensor-de-distancia-ultrasonico-con-luces-led

Este elemento nos va a servir en el futuro para poder decidir que caballo llega primero a la meta y así poder imprimir en la consola el marcador final de la carrera.
